# 音楽の変遷 — 集計仕様（v0.12.0）

NICO SHELFの「音楽の変遷」は、**保存済みデータ**から傾向を比較します。
音声ファイルの解析やユーザーの再生履歴の追跡は行いません。

## 3つの比較軸

1. **マイリスト別**: リスト名の数値末尾（例: `ぼかうた1`、`ぼかうた2`、`ぼかうた3`）を昇順に並べます。番号のないリスト（例: `最近のお気に入り`）は最初は除外し、チェックで追加できます。番号付きリストがなければすべて表示します。**リスト名が時間軸であるとは保証されません**。
2. **リスト内の表示順**: 1つのリストにある登録済み動画を、DBに保存されている`position`昇順で並べ、先頭から最大4等分します。位置情報がない行は元の行順に補完します。これは**登録日時の証明ではなく取得時の一覧表示順**です。
3. **動画の投稿年別**: `published_at`の年を利用して集計します。投稿日未取得の動画は除外し、分母の扱いを画面に示します。**発見年・追加年・再生年ではありません**。

## 分子と分母

- 分母: 各グループの動画数（同じグループ内では動画IDで重複除去）
- 分子: 指定項目に該当する動画の数
- 割合: `分子 / 分母 × 100`（小数1桁表示）
- 同じ動画が2つのマイリストにあれば、別々のリストにそれぞれ1回計上します
- 同じ動画が複数の歌唱者・タグ・作者に属する場合は複数項目に計上します（各項目の割合の合計は100%にならない）
- 分類が判定できない動画も分母に含みます。「判定情報がある動画」行でデータの充足度を表示します
- ジャンル・雰囲気は保存済みタグの推定結果であり、音声解析・リスニングによる正解ラベルではありません
- 歌唱者は既存の名寄せ処理に従い、同じ動画で同じキャラクターが複数表記されても1回です
- 作り手・投稿者は確認済み作曲者、製作者欄、投稿者から抽出します。同一人物の別名義をすべて識別できるとは限りません

## UIとプライバシー

- ダッシュボードとサイドバーから遷移
- 比較軸・分析項目・対象マイリストを変更可能
- 色付きセルを選ぶと、該当する楽曲が最大20曲表示され、ニコニコの動画ページへ移動可能
- 先頭と末尾の差は**パーセントポイント**です。好みが変わったことを断言する指標ではありません
- トレンド集計と描画は認証ユーザーの読み込み済み動画・所属のみを参照し、Supabaseに追加書き込みしません
- `src/app/trends.js` は計算、`src/ui/trends.js` は表示、`src/app/events.js` は操作イベントを担当します

## テスト

`npm test`で従来機能とトレンド集計のテストを実行します。
主要な境界ケース: 無所属動画／空リスト／削除済み登録／重複登録／名寄せ／投稿日欠損／XSS耐性／位置の並び替え。
