# 音楽の変遷：集計・グラフの読み方

## 比較の3軸

- **マイリスト別**：初期状態では全リストを、読み込んだライブラリの表示順で比較します。名前に含まれる数字・「お気に入り」などの語は判定に使いません。比較対象のチェックと上下ボタンで、グラフ・表の左から右への表示順を指定できます。すべて解除した場合は比較しません。選択・順番はIDで扱い、同名でも別リストとして表示します。設定は再読み込みまで保持し、アカウント切替で初期化します。
- **リスト内の表示順**：選んだマイリストの取得時表示順を最大4区間に分割します。これは実際の登録日時ではありません。
- **動画の投稿年**：曲が投稿された年別に比較します。実際に発見・聴取した年ではありません。

## 可視化

- 折れ線：選択した表示件数内の、各グループ内の**全動画に対する割合**を比較します。凡例を選ぶと該当項目の線が強調されます。
- 横棒：注目する1項目の割合をグループごとに表示します。各棒に曲数と分母を併記します。
- 分類率：そのグループのうち分析項目に有効な分類がある動画の比率を、別のバーで示します。分類率の低いグループの比較結果には注意してください。
- ヒートマップ：項目×グループの表。セルを押すと該当動画を表示します。
- 変化の表示：表示順の先頭と末尾のグループの差を**パーセントポイント（pt）**で表します。

**未分類動画を勝手に割合の分母から除外しません。** 同一曲が複数マイリストにあれば各マイリストに1回ずつ数え、複数歌唱者や複数ジャンルがあれば各項目に1回ずつ数えます。そのため列内の合計が100%を超えることがあります。

## 推定の限界

歌唱者は保存済み情報に加え、タイトル・概要欄で**明記された歌唱クレジット**や歌唱タグを使います。ジャンル・雰囲気はタグや概要欄の明示的な表記を使い、音声波形の解析は行いません。詳しくは `CLASSIFICATION.md` を参照してください。

分類できる動画の増減は、実際の音楽嗜好だけでなく情報取得状況の違いを反映する可能性があります。リスト間の変化は**傾向の観察**であって、厳密な時間変化の証明ではありません。

## 比較範囲と順番の扱い（v0.23.0）

リスト名は表示ラベルだけです。たとえば末尾が「10」「2」でも数値順へ変換しません。上下操作で指定した順の後ろへ新しいリストを追加し、存在しないIDは無視します。明示的に比較対象を選択した後に追加されたリストは、「すべて選択」か個別のチェックで含めてください。

この選択は「マイリスト別」の比較グループの設定です。「リスト内の表示順」は専用の選択欄から1リストを指定し、「動画の投稿年別」はライブラリ全体の有効な投稿年を使います。選択したリストが削除された場合、表示順分析で別リストへ自動的に切り替えません。

リストの並びを変更してもDBや元のニコニコの順序は変更しません。名前や並び順から、ユーザーが聴いた順序・好みの役割を推測しません。
