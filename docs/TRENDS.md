# 音楽の変遷：集計・グラフの読み方

## 比較の3軸

- **マイリスト別**：名前が数字で終わるリストを番号順に並べます。「最近のお気に入り」は初期設定で除外します。番号のないリストを含める設定も可能です。
- **リスト内の表示順**：選んだマイリストの取得時表示順を最大4区間に分割します。これは実際の登録日時ではありません。
- **動画の投稿年**：曲が投稿された年別に比較します。実際に発見・聴取した年ではありません。

## 可視化

- 折れ線：集計上位5項目の、各グループ内の**全動画に対する割合**を比較します。凡例を選ぶと該当項目の線が強調されます。
- 横棒：注目する1項目の割合をグループごとに表示します。各棒に曲数と分母を併記します。
- 分類率：そのグループのうち分析項目に有効な分類がある動画の比率を、別のバーで示します。分類率の低いグループの比較結果には注意してください。
- ヒートマップ：項目×グループの表。セルを押すと該当動画を表示します。
- 変化の表示：最初と最後のグループの差を**パーセントポイント（pt）**で表します。

**未分類動画を勝手に割合の分母から除外しません。** 同一曲が複数マイリストにあれば各マイリストに1回ずつ数え、複数歌唱者や複数ジャンルがあれば各項目に1回ずつ数えます。そのため列内の合計が100%を超えることがあります。

## 推定の限界

歌唱者は保存済み情報に加え、タイトル・概要欄で**明記された歌唱クレジット**や歌唱タグを使います。ジャンル・雰囲気はタグや概要欄の明示的な表記を使い、音声波形の解析は行いません。詳しくは `CLASSIFICATION.md` を参照してください。

分類できる動画の増減は、実際の音楽嗜好だけでなく情報取得状況の違いを反映する可能性があります。リスト間の変化は**傾向の観察**であって、厳密な時間変化の証明ではありません。
