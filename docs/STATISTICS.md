> **v0.20.0** — 対象マイリストはチェックボックスで複数選択できます。選択したリストの和集合を動画ID単位で重複除去します。空の選択は全体です。歌唱者の絞り込みは、その和集合に追加して適用します。6手法とCSVの対象IDに同じ選択が使われます。

# 統計分析（v0.21.0）

サイドバーの「統計分析」、スマホでは「散布図」画面上部の「統計分析へ」から開きます。対象マイリスト・歌唱者・項目を選び、「この条件で分析する」を押してください。条件を変えると以前の結果は消えます。

## データと計算

初期項目は「再生数・コメント数・ニコニコのマイリスト数」です（v0.20.3）。画面から項目を追加・解除できます。画面の手法名から番号を外しましたが、以下の番号は開発時に指定された分析手法との対応として残しています。

- すべて現在ログインしているユーザーの読み込み済みデータで計算します。分析用の外部APIやDB書き込みは使いません。Web Workerは同じサイトの静的資産です。
- 動画ID単位で1曲とします。複数マイリストへの重複登録で件数を増やしません。削除・非公開・取得失敗の明示された動画は分析から除外し、DBには残します。
- 相関は各ペアの必要な値がそろった曲を使い、セルごとにnを表示します。回帰・主成分・クラスタは選択した全項目の値がそろった曲を使います。欠損値を0で埋めません。
- 再生・コメント・マイリスト・いいね数は初期状態で自然対数 ln(1+x) に変換します。0件は有効な0です。項目名・結果CSVにも変換を示します。数値分析での動画時間は分、投稿時期は年の数値です。相関ルールの区間化は対数変換を使わず、元の再生数・秒数・UTC年を使います。
- 主成分とクラスタは変換後の各項目を標本平均0・標本標準偏差1へ標準化します。値が一定の列は除外し、その項目名を表示します。
- 音源・再生履歴は解析しません。ここでの数値による近さを、音の近さと解釈しないでください。タグからの分類には未分類や誤りがあり得ます。
- 分析結果はメモリ内だけに置き、条件変更・ライブラリの再取得・ユーザー切り替えで破棄します。実行中は中止できます。

## 番号順の実装

### 1. 相関分析

Spearman順位相関（同順位は平均順位）とPearson相関を切り替えられます。相関行列に係数とペアごとの有効曲数を表示します。3曲未満または値が一定なら係数は未定義（—）です。有意差検定や因果推定は行いません。

### 2. 回帰分析 / 3. 重回帰分析

切片を含む最小二乗法です。数値安定性のため説明変数を中心化・標準化し、SVDで解き、係数と標準誤差を元の分析尺度へ戻します。標準化係数とVIFも表示します。

- 単回帰は説明変数1項目、重回帰は複数項目です。重回帰の目的変数は説明変数から自動除外します。現版の説明変数は数値項目のみです。
- 必要曲数は最低でも説明変数数+2です。これは計算可能な下限で、結果の安定性を保証する件数ではありません。
- 定数列や、ほぼ線形従属した説明変数（標準化設計行列の条件数が1e8超）はエラーにします。VIFが10超、または条件数が1000超なら不安定さを案内します。
- R²、調整済みR²、RMSE、係数、標準誤差、係数の95%信頼区間、標準化係数、VIF、実測・当てはめ値・残差を表示します。残差が大きい上位20曲から詳細を開けます。
- R²・RMSEは使用した曲への当てはまりです。ホールドアウトによる予測精度ではありません。標準誤差は通常の最小二乗法のモデル仮定によるもので、頑健標準誤差ではありません。
- 係数の95%区間は、残差自由度 n−p−1 のt分布の0.975分位点を使い、係数±t臨界値×標準誤差で求めます。通常のOLSの仮定に基づく係数の区間で、個々の曲の予測区間ではありません。p値や有意マークは出さず、0を含むかだけで重要性を決めません。t分位点はjStatを使い、SciPyの計算と照合します。
- 目的変数を対数変換した場合、係数・残差も変換後の尺度です。指数で戻した値を「期待再生数」として表示することはしません。
- 反応率とその計算元の件数を同時に扱うと、数式上の関係が現れます。目的変数から作った率などを説明変数に選ばないよう、分析目的に応じて項目を選んでください。
- データは選択したライブラリの曲に限られます。係数を因果効果やニコニコ全体の傾向とは解釈しません。

### 5. 主成分分析

標準化行列のSVDから主成分を求めます。固有値、寄与率、累積寄与率、主成分の重み、元の標準化項目と主成分の相関（負荷量）を表示します。負荷量は重み×固有値の平方根です。

地図は第1・第2主成分の得点です。軸の符号に優劣はありません。主成分名を「人気」「良さ」などと自動で断定しません。丸め誤差程度の固有値の軸は表示得点を0とし、数値誤差を特徴の差として拡大表示しません。

### 9. パターンマイニング・相関ルール

1曲を1トランザクションとします。簡易分析は従来どおり1項目→1項目、Aprioriは左右合計2〜5項目（初期3項目）を探索します。A・B→C、A→B・C、A・B→C・Dなど、頻出項目集合のすべての非空・重複しない左右分割を評価します。

- 支持度 = AとBの全項目を持つ曲数 / 対象全曲数
- 確信度 = AとBの全項目を持つ曲数 / Aの全項目を持つ曲数
- リフト = 確信度 / 対象全体でBの全項目を持つ曲の割合
- 分類根拠がない曲や、保持した頻出項目を持たない曲も全曲数の分母に残します。項目は曲内で重複除去します。
- 対象曲の絞り込みはマイリストの和集合と歌唱者です。規則に使う属性は別に選択します。「所属マイリスト」は、対象曲の**現在のすべての所属先**（絞り込みで選択していないリストも含む）を項目にします。present=falseの所属は含めません。同名のリストはIDで区別します。

| 設定 | 簡易分析 | Apriori |
| --- | --- | --- |
| 最大項目集合サイズ（左右合計） | 2 | 2〜5、初期3 |
| 属性 | 歌唱者・推定ジャンル・推定雰囲気。追加で作者/投稿者・タグ | 9属性から複数選択 |
| 最小共起曲数 | 3 | 1〜1,000,000、初期3 |
| 最低支持度 | >0〜100%、初期2% | 同左 |
| 最低確信度 | 0〜100%、初期50% | 同左 |
| リフト | 1超 | 指定値以上、初期1.01 |
| 結論部 | 指定なし | 指定属性/項目を少なくとも1つ含む |
| 表示上限 | 50 | 1〜500、初期50 |
| 並べ順 | 共起曲数・リフト・確信度 | 同左 |

Aprioriの初期属性は、歌唱者・ジャンル・雰囲気・再生数・投稿時期・動画時間・所属マイリストです。作者/投稿者とタグは必要に応じて追加します。区間は下端を含み、上端を含みません。欠損・無効・負値から0の区間を作りません。

| 属性 | 初期の区切り | 例 |
| --- | --- | --- |
| 再生数 | 10,000 / 100,000 / 1,000,000 | 1万再生未満、1万以上10万再生未満 |
| 投稿時期 | 2010 / 2020 / 2023 / 2027 | 2000〜2009年、2023〜2026年、2027〜2100年 |
| 動画時間（秒） | 120 / 180 / 240 / 300 | 2分未満、3分以上4分未満、5分以上 |

区切りは小さい順の数値をカンマで最大12個指定します。投稿年は2001〜2100の整数、データ自体は2000〜2100年が対象です。再生数と動画時間の区切りは0より大きく1兆未満です。

**計算と上限**：最小件数は `max(最小共起曲数, ceil(支持度 × 全曲数))`。浮動小数点の境界誤差に1e-12の許容を使います。頻出1項目の頻度上位80個を採用し、同頻度はラベル・キー順です。以後の規則はこの80項目の範囲に限ります。頻出項目集合のprefix joinと全直前部分集合の検査で枝刈りし、ソート済みのトランザクションID列の積集合で数えます。

1回の分析の上限は、候補100,000・join試行200,000・頻出項目集合15,000・積集合の比較20,000,000・規則の分割試行300,000です。探索上限に達した段階の項目集合は全て捨て、完了したサイズ以下からのみ規則を生成します。規則生成上限では生成済み規則の範囲での上位結果です。どちらも警告を表示し、全体の上位や完全探索とは主張しません。規則は条件を評価した後、指定の並べ順で上位件数を保持します。省略項目数・完了サイズ・各サイズの集合数・部分結果の状態を出力します。

ルールを押すと共起する曲を確認できます。タグ由来の分類や、同じ曲を選んで作ったマイリスト同士では、当然の関連が強く出る場合があります。対象は自分の選んだ曲です。因果関係やニコニコ全体の傾向を示すものではありません。

### 10. 階層的クラスタリング・k-means

- **k-means**：k-means++初期化、固定シード、5回の初期化を比較し、群内平方和が最小の結果を採用します。各回最大100反復。空群は遠い点を移して修復します。有効な全曲を使い、指定kより特徴の異なる点が少ない場合は停止します。
- **階層型**：標準化後のユークリッド距離、平均連結法（群サイズによる加重更新）です。指定kで切った結果を表示します。ブラウザの負荷を抑えるため最大300曲。有効曲がそれ以上なら動画IDの固定ハッシュ順で300曲を抽出し、対象・標本外件数を表示します。同じ動画集合なら入力順によらず同じ標本です。統計的推測のための無作為標本とは主張しません。
- 計算は選択した全数値項目を使います。表示用の地図だけを2主成分に圧縮します。群番号は順位ではありません。群の平均と各曲の所属をCSVへ出せます。
- 樹形図は選択したk群より上の枝のみ表示し、群内を折りたたみます。枝に統合距離を表示します。
- いずれも分類の正解を保証するものではありません。kや項目を変えて比較できます。

### グループ数kの比較

同じ対象曲・同じ標準化・同じ手法で、可能な範囲のk=2〜8を比較します。群内平方和、平均シルエット係数、最小群・最大群の曲数、収束状態を表示し、表のボタンからそのkで再分析できます。主結果と比較表の選択kの群内平方和は一致します。

- シルエットは各点の群内平均距離aと、他群への平均距離の最小値bから (b−a)/max(a,b) を求めて平均します。距離は標準化後のユークリッド距離です。1点群の寄与は0、群数が1または全点が別群の場合は未定義（—）です。
- 計算量を抑えるため、評価する点は最大300曲に限定します。動画IDのハッシュで同じ曲を選び、各点からの距離の相手には、各kで計算に使った全対象曲を使います。300曲を超える場合、表示する係数は標本上の目安であり、評価曲数を明示します。
- k-meansの当てはめと群内平方和は全対象曲を使います。階層型の本体は従来どおり最大300曲です。この本体の制限と、シルエット評価点の制限は別です。
- 係数が高いkを自動で正解とはせず、曲一覧、群の特徴、極端に小さい群の有無も確認します。

## 結果の持ち出し

結果CSVはUTF-8 BOM付きです。条件、変換方式、有効件数、各手法の結果を含みます。回帰・主成分・クラスタには曲単位の結果も含めます。曲一覧は画面では先頭100曲まで、クラスタ全曲の所属はCSVで確認できます。ルールはCSVでも表示対象の上位件数（簡易50、Aprioriは指定数）です。左右の項目配列と該当動画IDをJSON列で保存し、最低件数・区切り・結論部の指定・探索完了/部分結果も記録します。

### 相関ルールの分析元CSV・ARFF

- 再計算せず、実際に分析した結果内のトランザクションと頻出上位80項目から出力します。対象曲・公開状態の除外・重複除去・区間が結果と一致します。空トランザクションも残ります。全件の元DBエクスポートではありません。
- 分析元CSVはUTF-8 BOM付きで、動画ID・タイトル・項目別の1/0を保存します。0は「観測された項目がない」であり、欠損と否定の事実を区別しません。文字列にはCSV数式注入対策を適用します。
- ARFFはUTF-8・BOMなしの密形式です。各項目は単一値の名義属性 `{present}`。項目があるときは `present`、項目がない/不明なら `?` にします。動画IDやタイトルは規則の属性に含めません。引用符・バックスラッシュ・改行をエスケープし、属性名が衝突する場合は番号を付けます。
- WekaはUTF-8で開き、Aprioriの `treatZeroAsMissing=false` を使います。trueにすると唯一の名義値presentが消えます。1/0のCSVをそのまま使うと不在側の規則も探索され得るため、比較にはARFFを使ってください。
- Wekaでは支持度を段階的に下げる初期設定や表示件数、評価指標が結果を変えます。支持度の上下限、確信度、最低共起件数に相当する支持度、リフト、結論部の絞り込みをそろえ、必要なら出力後に左右合計の最大項目数で絞り込んで比較します。表示件数と同順位の順番まで常に一致するという保証はありません。
- **実Wekaでのファイル読込・実行比較は未実施です。** 以下のテストはブラウザ実装と独立した総当たり計算・手計算との比較です。
