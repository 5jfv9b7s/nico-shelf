# 統計分析（v0.18.0）

サイドバーの「統計分析」、スマホでは「散布図」画面上部の「統計分析へ」から開きます。対象マイリスト・歌唱者・項目を選び、「この条件で分析する」を押してください。条件を変えると以前の結果は消えます。

## データと計算

- すべて現在ログインしているユーザーの読み込み済みデータで計算します。分析用の外部APIやDB書き込みは使いません。Web Workerは同じサイトの静的資産です。
- 動画ID単位で1曲とします。複数マイリストへの重複登録で件数を増やしません。削除・非公開・取得失敗の明示された動画は分析から除外し、DBには残します。
- 相関は各ペアの必要な値がそろった曲を使い、セルごとにnを表示します。回帰・主成分・クラスタは選択した全項目の値がそろった曲を使います。欠損値を0で埋めません。
- 再生・コメント・マイリスト・いいね数は初期状態で自然対数 ln(1+x) に変換します。0件は有効な0です。項目名・結果CSVにも変換を示します。動画時間は分、投稿時期は年の数値です。
- 主成分とクラスタは変換後の各項目を標本平均0・標本標準偏差1へ標準化します。値が一定の列は除外し、その項目名を表示します。
- 音源・再生履歴は解析しません。ここでの数値による近さを、音の近さと解釈しないでください。タグからの分類には未分類や誤りがあり得ます。
- 分析結果はメモリ内だけに置き、条件変更・ライブラリの再取得・ユーザー切り替えで破棄します。実行中は中止できます。

## 番号順の実装

### 1. 相関分析

Spearman順位相関（同順位は平均順位）とPearson相関を切り替えられます。相関行列に係数とペアごとの有効曲数を表示します。3曲未満または値が一定なら係数は未定義（—）です。有意差検定や因果推定は行いません。

### 2. 回帰分析 / 3. 重回帰分析

切片を含む最小二乗法です。数値安定性のため説明変数を中心化・標準化し、SVDで解き、係数と標準誤差を元の分析尺度へ戻します。標準化係数とVIFも表示します。

- 単回帰は説明変数1項目、重回帰は複数項目です。重回帰の目的変数は説明変数から自動除外します。現版の説明変数は数値項目のみです。
- 必要曲数は最低でも説明変数数+2です。これは計算可能な下限で、結果の安定性を保証する件数ではありません。
- 定数列や、ほぼ線形従属した説明変数（標準化設計行列の条件数が1e8超）はエラーにします。VIFが10超、または条件数が1000超なら不安定さを案内します。
- R²、調整済みR²、RMSE、係数、標準誤差、標準化係数、VIF、実測・当てはめ値・残差を表示します。残差が大きい上位20曲から詳細を開けます。
- R²・RMSEは使用した曲への当てはまりです。ホールドアウトによる予測精度ではありません。標準誤差は通常の最小二乗法のモデル仮定によるもので、頑健標準誤差ではありません。
- 目的変数を対数変換した場合、係数・残差も変換後の尺度です。指数で戻した値を「期待再生数」として表示することはしません。
- 反応率とその計算元の件数を同時に扱うと、数式上の関係が現れます。目的変数から作った率などを説明変数に選ばないよう、分析目的に応じて項目を選んでください。
- データは選択したライブラリの曲に限られます。係数を因果効果やニコニコ全体の傾向とは解釈しません。

### 5. 主成分分析

標準化行列のSVDから主成分を求めます。固有値、寄与率、累積寄与率、主成分の重み、元の標準化項目と主成分の相関（負荷量）を表示します。負荷量は重み×固有値の平方根です。

地図は第1・第2主成分の得点です。軸の符号に優劣はありません。主成分名を「人気」「良さ」などと自動で断定しません。丸め誤差程度の固有値の軸は表示得点を0とし、数値誤差を特徴の差として拡大表示しません。

### 9. パターンマイニング・相関ルール

1曲を1トランザクションとし、歌唱者・推定ジャンル・推定雰囲気から頻出2項目を数えます。設定で作り手・投稿者と保存済みタグも加えられます。1項目→1項目のルールに限定しています。

- 支持度 = AとBを持つ曲数 / 対象全曲数
- 確信度 = AとBを持つ曲数 / Aを持つ曲数
- リフト = 確信度 / 対象全体でのBの割合
- 分類根拠がない曲も全曲数の分母に含み、根拠のある曲数を別表示します。
- 共起が3曲以上かつ指定支持度以上、指定確信度以上、リフト>1のルールを表示します。出現項目は頻度上位80個まで、ルールはリフト順の上位50件です。省略した件数も表示します。
- ルールを押すと共起する曲を確認できます。同じ分類根拠に由来するタグ間では、意味上当然のルールが強く出る場合があります。

### 10. 階層的クラスタリング・k-means

- **k-means**：k-means++初期化、固定シード、5回の初期化を比較し、群内平方和が最小の結果を採用します。各回最大100反復。空群は遠い点を移して修復します。有効な全曲を使い、指定kより特徴の異なる点が少ない場合は停止します。
- **階層型**：標準化後のユークリッド距離、平均連結法（群サイズによる加重更新）です。指定kで切った結果を表示します。ブラウザの負荷を抑えるため最大300曲。有効曲がそれ以上なら動画IDの固定ハッシュ順で300曲を抽出し、対象・標本外件数を表示します。同じ動画集合なら入力順によらず同じ標本です。統計的推測のための無作為標本とは主張しません。
- 計算は選択した全数値項目を使います。表示用の地図だけを2主成分に圧縮します。群番号は順位ではありません。群の平均と各曲の所属をCSVへ出せます。
- 樹形図は選択したk群より上の枝のみ表示し、群内を折りたたみます。枝に統合距離を表示します。
- いずれも分類の正解を保証するものではありません。kや項目を変えて比較できます。

## 結果の持ち出し

結果CSVはUTF-8 BOM付きです。条件、変換方式、有効件数、各手法の結果を含みます。回帰・主成分・クラスタには曲単位の結果も含めます。曲一覧は画面では先頭100曲まで、クラスタ全曲の所属はCSVで確認できます。ルールはCSVでも表示対象の上位50件です。

## 検証と構成

- tests/fixtures/analytics-reference.json は架空データです。NumPyのlstsq・SVDとSciPyの平均連結法で独立に求めた係数・標準誤差・VIF・主成分・統合距離を照合します。
- 欠損、同順位、定数列、共線性、空群、再現性、標本、CSVの数式注入対策、HTMLエスケープ、Worker実行・中止・ユーザー切り替えをテストします。
- Web Workerは同一サイトから読み込むためCSPに worker-src 'self' を追加しています。外部CDNは使いません。ml-matrix をロックファイルで固定しています。
- 実ユーザーのデータ、本番環境、実機の画面レイアウトは別途確認が必要です。

計算：src/app/analytics/、画面：src/ui/analysis.js、チャート：src/ui/analysis-charts.js、Worker制御：src/app/analysis-controller.js。
