# 散布図・歌唱キャラクターの配色（v0.14）

## 画面

サイドバーの **「散布図」** から開きます。次の軸をX/Yに選択できます。

| データ | 単位 | 軸 | 備考 |
|---|---|---|---|
| 再生数 | 回 | 対数 (`log10(値+1)`) | ゼロ再生も表示。取得時点の累積数 |
| コメント数 | 件 | 対数 (`log10(値+1)`) | 同上 |
| いいね数 | 件 | 対数 (`log10(値+1)`) | 取得できていない動画は除外 |
| 動画時間 | 分 | 線形 | `duration` 秒を60で除算 |
| 投稿時期 | 年（暦年の小数） | 線形 | 投稿年 ≠ ユーザーが発見・聴取した年 |

保存済み動画IDは一度だけ描画。現在の軸のどちらかが不明の場合は無理に0として扱わず除外します。フィルター対象の何曲が描画できたかを表示します。

点の色は最初の歌唱キャラクターを用い、複数人歌唱は輪郭を白くして区別します。特定キャラクターに絞り込んだ場合は、そのキャラの色で統一します。動画をクリック／Enter／Spaceで詳細ダイアログを開きます。マウスホバーでは元の値と動画名を確認できます。

**順位相関**はSpearmanのρ（同順位には平均順位を割当）。点が3個未満、X/Yの値が定数、X/Yが同じ項目の場合は表示しません。相関は因果や楽曲の好みを意味しません。

`src/app/character-colors.js` の `CHARACTER_COLORS` で一元管理しています。歌唱者は `canonicalVoice()` に通してから色を引くので、音街ウナ Spicy/Sugar/SVなどは一貫して音街ウナ色になります。

## 実装方針

- `src/app/character-colors.js` — 色パレットと名寄せ連携
- `src/app/scatter.js` — 散布図の純関数、欠損と0の判別、順位相関
- `src/ui/scatter.js` — SVGと操作画面のみ
- `src/ui/trend-charts.js` / `src/ui/trends.js` — 既存推移グラフへの色適用
- `src/ui/views.js` — ダッシュボードの歌唱者棒・リスト別傾向への色適用
- `src/app/events.js` / `src/app/state.js` — 絞り込み・軸選択・詳細へのイベント
- `tests/v014-charts.test.mjs` — 色、軸、欠損、相関、アクセス可能性の回帰テスト

グラフの値はメタデータに基づきます。新規動画を追加した場合、メタデータ補完後に再描画できます。Cloudflare・SupabaseのテーブルおよびTampermonkey連携に変更はありません。

## v0.14.3: 非公開・削除・取得失敗の除外

`src/app/scatter-availability.js` が `video.status` と元データのプレースホルダー名を調べます。`deleted` / `削除済み`、`private` / `非公開`、`Deleted video` / `Private video` は除外し、`取得失敗` は削除と断定せず **公開状態未確認** として一時的に除外します。

- 除外の対象は散布図の点・集計件数・歌唱者凡例・Spearman順位相関です。**動画DB、マイリスト履歴、評価、メモは削除しません**。
- `取得成功` / `部分取得` の動画、再生数が0の動画は、必要な軸情報があれば通常どおり対象です。
- タイトルに `削除` が含まれるだけで除外せず、定型的なプラットフォームのプレースホルダーのみ判定します。
- 後からメタデータの取得に成功したら状態を `取得成功` に更新し、適切な動画名を取り込みます。
- ニコニコのライブ状態を常時監視しているわけではありません。保存時点のデータに基づく判定です。

## 3D散布図（v0.15）

- X / Y / Z の3軸をそれぞれ選択します。選べる指標は2D版と共通です。
- `src/app/scatter3d.js` は既存の公開状態判定・欠損処理を再利用し、3軸とも数値がある動画だけ返します。
- `src/ui/scatter3d.js` はCanvas描画と回転・ズーム・クリック操作を担当します。バックエンドやDBにアクセスしません。
- タブや2D/3D切り替え時に古いCanvasイベントとResizeObserverを解除します。
- 視点変更は画面内の一時的な状態であり、Supabaseへ書き込みません。
- 再生数・コメント数・マイリスト数などの対数目盛は0を描画できる `log10(value + 1)` です。
- 欠損値は0として扱わず、削除・非公開・取得失敗は相関・散布図ともに対象外です。
- 3Dは空間的な配置を見るための可視化で、3変数間の単一の相関係数は表示しません。
- 点が重なるときは前面を優先してクリック判定します。色は歌唱者名に由来し、すべてが公式HEXではありません。
