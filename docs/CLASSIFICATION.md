# 歌唱者・ジャンル・作曲者の判定仕様（v0.13）

## 基本原則

- 既存の保存済み歌唱者（VocaDBを含む）は保持し、**ユーザーの手動確定**を最優先します。
- 歌唱キャラクター名とエンジン別表記は別物です。`音街ウナ Spicy` と `音街ウナ-SV` は原表記で検索でき、キャラクター別集計では `音街ウナ` になります。
- タイトル・概要欄・タグは**テキストによる根拠**であり、音声ファイル自体の歌唱者やジャンルを証明するものではありません。
- 自動判定はブラウザ上の表示・集計に利用します。`videos.voices`、動画の元タイトル・元説明文、手動確定値を勝手に書き換えません。

## 歌唱者を採用する根拠

| 根拠 | 扱い | 例 |
|---|---|---|
| ユーザーが詳細画面で設定した歌唱者 | 最優先で確定 | `音街ウナ、足立レイ` |
| 取り込み済みの `voices` | 基本データとして採用 | `音街ウナ Spicy` |
| タイトルの明示的な歌唱欄 | 採用 | `曲名 feat. 重音テト`、`曲名 / 音街ウナと星界` |
| 概要欄の明示的なクレジット | 採用 | `Vocal: 音街ウナ`、`歌唱：初音ミク` |
| 歌唱者名そのもの／歌唱曲タグ | 採用 | `音街ウナ`、`重音テトオリジナル曲` |
| タイトルでの曖昧な言及 | **要確認** | `初音ミクの誕生日を祝う曲` |
| 概要欄での自由な言及 | **要確認** | `音街ウナの曲が好きです` |
| 歌唱以外の明記クレジット | 採用しない | `原曲：初音ミクの曲`、`イラスト：音街ウナ` |

要確認候補はライブラリの **未整理 → 歌唱者に要確認候補あり**で検索でき、動画詳細でも根拠を確認できます。誤判定や見落としがあれば詳細画面の手動確定を使用してください。

## ジャンル・雰囲気

分類に利用するのは `genre` フィールド、保存済みタグ（VocaDBタグ含む）、概要欄の**明示的な分類行**だけです。例：

- `ジャンル：ボカロック`
- `Genre: synth pop`
- `雰囲気：切ない・静かな`
- `Mood: happy`

歌詞や宣伝文にたまたま `ロック`、`かわいい`、`切ない` と書かれていても分類しません。サポートするジャンル・雰囲気の辞書は `src/discovery.js` にあり、完全ではありません。

## 作曲者の補助抽出

元の `producers`・`composers`・`uploader` を保持したまま、概要欄の `作曲：`、`作編曲：`、`Music:` などから名前を追加します。

投稿者＝作曲者とは限りません。分析の軸名も **「作り手・投稿者」** としており、確定した作曲者ランキングと誤認させないようにしています。

## 誤判定の扱い

1. 自動判定候補が多くても、曖昧な言及は割合の計算に含めません。
2. 手動確定で分類の優先度を上げられます。元データのクレジットは削除しません。
3. 複数歌唱の動画はキャラクターごとに1回ずつ集計されます。
4. ルールを変更した場合は、少なくとも `tests/v013-voices.test.mjs` と `tests/discovery.test.mjs` を確認してください。
