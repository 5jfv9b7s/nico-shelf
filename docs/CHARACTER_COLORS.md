# キャラクター配色と表示数（v0.14.2）

キャラクター配色は `src/app/character-colors.js` にまとめています。

- `CHARACTER_COLORS` はグラフ用に選定した色です。**公式HEX値だと断定しないでください**。
- 色の登録がないキャラクター名は、安定したハッシュから算出する自動色になります。任意のカラーテーマを付けてはいません。
- `canonicalVoice()` で同じキャラクターとして認識したSVなどの版違いは同じ色です。
- 複数歌唱者は全員集計しますが、散布図の点色は代表（先頭）1人分です。
- 未判定の歌唱者は灰色を使います。

## 表示件数
- ダッシュボード歌唱者ランキングとマイリスト別比較：上位5・10・15・20・30・全員。
- 音楽の変遷：5・10・20・30・すべて（項目数はユーザー操作で選択）。
- 散布図：凡例15・30・全員。点はデータが揃った全曲を描画します。

## キャラクターを追加したい場合
1. 正規の名前を `src/app/voice-detection.js` の `VOICE_RULES` に追加。
2. 必要なら `src/app/character-colors.js` へ近似色を追記。公式で指定された色ではない場合はコメントを付ける。
3. `tests/v0142-characters.test.mjs` に名寄せと色の回帰テストを追加する。
4. `npm test` を実行する。

## 注意
タイトル・概要欄に現れた名前が必ず歌唱者とは限りません。歌唱判定は明示的な歌唱クレジット／タグなどに限ります。保存済みDBは自動変更しません。
