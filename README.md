# NICO SHELF v0.6.2 β — 接続修正パッチ

## 原因と修正

v0.6.1 はアプリのページとTampermonkeyとの通信に `window.postMessage` のみを使用していました。Chrome拡張機能の分離実行環境によっては送信元の判定が通常のページと異なり、アプリ側がメッセージを無視する可能性があります。

v0.6.2 は **DOM CustomEventによる同一タブ内の通知** を追加し、従来の `postMessage` と併用します。Tampermonkey内の異なるサイト間は従来通り `GM_setValue` と `GM_getValue` で通信します。拡張機能の分離ワールドで DOM CustomEvent が受信できることを Chromium で確認済みです。ニコニコ本番への書き込みは未検証です。

## 更新方法（v0.6.1 → v0.6.2）

1. 必要であればNICO SHELFからデータのバックアップを出力します（DBそのものは変更しません）。
2. `src/bridge.js` と `src/main.js` をGitHubリポジトリに上書きしてコミットします。Cloudflareの自動デプロイが完了するのを確認します。
3. **Tampermonkeyのダッシュボードで現在の `NICO SHELF Direct Bridge` を編集し**、ファイル `bridge/nico-shelf-direct.user.js` の内容を丸ごと上書き、Ctrl+Sで保存します。新しい別スクリプトとして増やさないでください。
4. 旧 v0.6/v0.6.1 の重複スクリプトがあれば無効化します。直接登録スクリプトは1つだけ有効にします。
5. 既存のニコニコ接続用タブを閉じ、公開した NICO SHELF のタブを Ctrl+Shift+R で再読み込みします。
6. 「動画を登録」→「① ニコニコと接続」→新しいニコニコタブで「接続を許可」。ニコニコ側パネルに `v0.6.2` と表示されることを確認します。
7. NICO SHELFが「接続中」となったら、未登録の動画で「② 登録状況を確認」まで試します。直接登録は、その確認が成功してから1件だけ試してください。

SupabaseのSQL追加、Googleログイン設定変更、Cloudflare環境変数変更はありません。

## 動作確認

- Node.jsの自動テスト **22件すべて成功**（DOMイベントと従来のタブ間通信の模擬テストを含む）
- Chromiumの**isolated world**とページ本体の間でDOM CustomEventが往復することを確認（拡張機能そのものではなく、隔離コンテキストの再現）
- 実際のTampermonkey拡張機能 / ニコニコログインアカウントでの動作は未確認

## まだ接続できない場合

- アプリで「v0.6.2が検出できません」：アプリ側では古いスクリプトが動作中です。公開URLがTampermonkeyの `@match` に一致しているか、サイトアクセス許可を確認します。
- アプリからのイベントには応答できるがニコニコから通知が届かない：ニコニコ側パネルのバージョン確認、両タブで同じTampermonkeyスクリプトが起動しているか確認します。
- ニコニコのタブにv0.6.2のパネルが表示されない：スクリプトがそのドメインで動作していません。

**注意：** ニコニコの非公式APIによる書き込みは仕様変更の影響を受ける可能性があるため、初回は「② 登録状況を確認」で読み取りだけ試してください。Cookie、パスワードやSupabaseの秘密鍵を共有しないでください。
