# NICO SHELF v0.14.2 歌唱者判定修正パッチ

## 修正内容

- 歌唱者判定辞書へ正しい表記「彩澄りりせ」を追加します。
- 動画 `sm46636822`（『secret base ～君がくれたもの～』カバー）のタイトルとタグから、「桜乃そら」と「彩澄りりせ」の両方を検出します。
- 「ZONE」の英字の一部分から「OИE」を歌唱者と誤判定する問題を防ぎます。
- 原データやSupabaseのテーブルは変更しません。

## 更新方法

1. NICO SHELFでJSONバックアップを保存します。
2. ZIP内の `src/app/voice-detection.js` をGitHubの同じパスに上書きします。
3. `tests/v013-voices.test.mjs` も同じパスへ上書きして、回帰テストを追加します。
4. Cloudflareの自動デプロイ成功後、ブラウザを強制再読み込みします。
5. 該当動画の詳細画面の「歌唱キャラ」と「歌唱者の判定根拠」を確認します。

Googleログイン、Supabase SQL、Tampermonkeyの設定変更は不要です。

## 切り分けの注意

元のv0.14.2ソースでも「桜乃そら」の名前は判定辞書に存在し、タイトルをそのまま与えたテストでは検出されます。一方「彩澄りりせ」は辞書にありませんでした。したがって、ユーザー画面で「桜乃そら」も未判定だった原因は、この辞書漏れだけでは説明できません。パッチ後も「未判定」が続く場合は、Cloudflareにデプロイされた実際のソースと、アプリ内に保存されている動画メタデータの内容を確認してください。

## テスト

修正済みソースをv0.14.2全ファイル版に適用して `node --test tests/*.test.mjs` を実行し、137件すべて成功しています。Cloudflareの本番デプロイと実ブラウザでの表示確認は未実施です。
