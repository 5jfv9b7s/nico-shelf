# NICO SHELF v0.9.0 β — 検索プリセット・CSV出力・再発見

Googleログイン + Supabase + Cloudflare Workers で動くニコニコ動画マイリスト管理アプリです。**v0.7の直接登録・差分同期を引き継ぎつつ、4つの新機能を追加**しています。元のSQLite/JSONをGitHubへ置く必要はありません。


## v0.9.0 新機能

今回の更新は **v0.8.1 をベース**にした機能追加です。v0.8で使えていたニコニコ直接登録・差分同期・Tampermonkeyスクリプトには変更を加えていません。

- **保存検索（最大20件）**：曲名、歌唱者、ジャンル、雰囲気、投稿年、作者、整理状況、並び順、マイリスト、ジャケット表示の状態をアカウント別に保存。別端末からも呼び出せます。同名で保存すると確認後に上書きします。
- **整理状況の絞り込み**：「どのマイリストにも未所属」「歌唱者が未判定」「未評価」「動画情報が不足」を追加。他の検索条件と組み合わせられます。
- **検索結果CSV出力**：今の絞り込みに合う全動画を、表示ページ数に制限されず出力。曲名、動画URL、歌唱者、作者、推定ジャンル・雰囲気、登録先、メモ、評価など17列。Excelを考慮したUTF-8 BOMと数式対策付き。**検索用CSVは分析・共有向けで、JSONバックアップとは形式が異なります。****メモなどの私的情報も含むため、共有前には内容を確認してください。**
- **条件からランダムに1曲**：現在の検索条件に合う動画からランダムに1曲を選んで、詳細画面を開く。知らなかった曲や昔の曲の再発見向け。

### 必須：Supabaseで一度だけSQLを実行

1. 既存のNICO SHELFから **JSONバックアップを保存**する。
2. Supabaseの該当プロジェクト → SQL Editorで、`supabase/migrations/202611100001_saved_searches.sql` を実行する。これは `saved_searches` テーブルを作成し、**本人の行だけアクセスできるRLS** を設定するためのSQL。既存の `videos`、`playlists`、`entries`、`user_meta` は変更しない。
3. 更新用ZIPを展開し、**新規の `src/app/saved-searches.js`、`src/app/search.js`、`src/app/csv-export.js` とテスト等を含めて**GitHubの同じパスにアップロードする。
4. Cloudflareのデプロイ成功を確認し、NICO SHELFを再読み込みする。
5. ライブラリで「歌唱キャラ：音街ウナ」などを選択 → 「＋ この条件を保存」→ 名前を付ける。次回から「保存検索」で選択できる。

**Tampermonkeyの更新・Cloudflare環境変数の変更は不要です。**

検索条件はJSONバックアップにも保存され、同形式のバックアップから復元できます。「全データを削除」では保存条件も削除します。

SQL未適用の場合も検索・ニコニコ連携などの従来機能は利用できますが、保存検索ボタンにはSQL適用を促す警告を出します。

**検証：`npm test` で61件成功（既存44件＋新規17件）。** ソースの構文チェック済み。作業環境のnpmレジストリへのネットワーク接続ができず、今回もVite本番ビルド・Supabaseでの実書き込み・実ブラウザ操作は未確認です。

## v0.8.0で追加した機能（引き続き利用可能）
### 新機能

**1. 歌唱者の名寄せ（表示・検索）**
- 歌唱キャラクター名での統計を追加。例：`音街ウナ-SV`、`音街ウナ Spicy`、`Synthesizer V AI 音街ウナ`、`音街ウナ (Unknown)` は「音街ウナ」に統合。
- 「ダッシュボード → 歌唱者ランキング」のセレクトから「キャラクター別／元の歌唱者表記」を切替。マイリスト別の歌唱者割合も同じ単位で表示します。
- ライブラリでは「歌唱キャラ」を選んだ後、細かい「原表記」を絞り込めます。
- DBの `voices` は書き換えません。動画の「… → 詳細」から、個人用の歌唱者補正 `verified_voice` を編集できます。既存のメモやお気に入りは保持されます。

**2. 詳細検索・分析**
- 「ライブラリ」で歌唱キャラ、原表記、ジャンル、雰囲気、投稿年、作者・投稿者、マイリスト、全文検索を組み合わせて絞り込み。
- ジャンル・雰囲気の判定は**ニコニコ／VocaDB等の既存タグを文字列ルールで分類した推定**で、音声解析ではありません。誤分類と未分類はあり得ます。
- ダッシュボードにタグ由来のジャンル・雰囲気ランキング。投稿者は作曲者を意味するとは限りません。`verified_composer` に本人が補正入力できます。
- 「↺ リセット」は従来通りソートだけ戻します。「条件クリア」は検索・詳細フィルタを解除し、ソートを維持します。

**3. 新規動画のメタデータ自動補完**
- v0.7と同じログイン済みニコニコタブを利用し、Tampermonkey の `GM_xmlhttpRequest` で **getthumbinfo** にアクセスします。取得候補：タイトル・説明文・サムネイル・投稿日・動画長・再生数・コメント数・マイリスト数・ジャンル・タグ・投稿者。タグに明示された歌唱者は推定し、既存の歌唱者情報がない場合のみ記録します。作曲者はAPIだけでは確定できません。
- 直接登録成功後に、**登録先への追加とDB反映を確定させてから**その動画の詳細を1件取得します。詳細取得に失敗しても登録成功は取り消しません。
- 差分同期でDBに**初登場した動画**は、同期成功後に最大5件を補完。大量の追加は「データと設定 → 動画メタデータを補完」から最大15件ずつ再取得できます。
- メタデータの無い動画のみ対象とし、21日以内に取得成功した動画はバッチ候補から外します。既存の説明文・VocaDBクレジット・歌唱者・タグを自動で消しません。
- APIが非公開動画や削除動画を返さない場合はスキップ。**毎回1117動画を再取得する仕組みではありません。**

**4. ビジュアル表示の改善**
- 動画サムネイルがあれば表示し、クリックするとニコニコの動画ページを開きます。表示不能なら音符を表示。
- `▦ ジャケット表示` と `≡ リスト表示` を切替。リスト内にジャンル・雰囲気・名寄せした歌唱者を表示。
- 動画詳細でもサムネイル・元の歌唱者情報・タグを見られます。

## 参考：旧v0.7 → v0.8 の更新手順

1. **NICO SHELF → データと設定 → JSONバックアップを保存**。ニコニコに登録済みの動画は変更されません。
2. 更新用ZIPを展開し、**`src/main.js`、`src/bridge.js`、新規の`src/discovery.js`、`src/style.css`、`bridge/nico-shelf-direct.user.js` など**を、GitHub `5jfv9b7s/nico-shelf` の同じ位置に置いてコミットします。リポジトリのルートに `package.json` を配置。
3. Cloudflare Workersのビルドが成功したことを確認。既存の `wrangler.jsonc`、`npm run build`、`npx wrangler deploy`、環境変数は変更不要です。
4. Tampermonkeyの **既存v0.7 Direct Bridgeを編集**して、ZIPの `bridge/nico-shelf-direct.user.js` の内容を全文貼り付け、保存します。`@connect ext.nicovideo.jp` に伴う権限確認が出れば内容を確認して許可してください。
5. **Direct Bridgeはv0.8.0だけON**にして、以前のv0.6.*・v0.7スクリプトはOFF。接続用のニコニコタブを閉じ、NICO SHELFを `Ctrl + Shift + R` で再読み込み。
6. まず「ライブラリ」の歌唱キャラ「音街ウナ」を選び、名寄せを確認。次に「ニコニコとの差分同期」などから接続し、「ライブラリ → いずれかの動画の『…』→ ニコニコから詳細情報を補完」で**1動画だけ補完**してください。まとめて補完する場合は「データと設定 → 動画メタデータを補完」で最大15件ずつ取得できます。直接登録・差分同期も実機で再確認を推奨します。

**SupabaseのSQL追加は不要です。** 既存の `videos` の `metadata_updated_at`・`thumb`・`tags`・`voices` と、`user_meta` の `verified_voice`・`verified_composer` を利用します。すでに v0.5 の `202611090002_sync_snapshot.sql` を適用済みであることが前提です。

## 確認状況・制限

- Node.js標準 `node --test` による自動テスト44件が成功。`node --check` で主なJavaScriptファイルを構文検査。
- 本環境のnpm依存パッケージ取得がタイムアウトしたため、**Vite本番ビルド・Supabaseでの実書き込み・Chrome＋Tampermonkeyでの実機検証は未確認**。更新後のCloudflareデプロイと自分のニコニコアカウントでの動作を確認してください。
- getthumbinfoは外部APIであり、今後の変更・HTTPエラー・動画非公開によって補完が失敗することがあります。歌唱者の推定はタグの内容に依存し、正解を保証しません。
- NICO SHELFにGoogleログインするだけでは、ニコニコに自動ログインしません。Cookieやパスワードはクラウドへ保存しません。
- ニコニコへの直接登録と差分同期は従来と同じ非公式APIを使います。登録先の「ぼかうた1→2→3」優先、最近のお気に入りへの自動登録禁止は維持しています。
