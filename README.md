# NICO SHELF v0.6.1 β — 直接登録の接続修正

## 修正内容

v0.6では、ニコニコ側の「接続中」が表示されてもNICO SHELF側が「未接続」のままになる場合がありました。これはニコニコ側で「接続を許可」が押されたことと、クラウド版アプリに接続確認が届いたことが別だからです。

v0.6.1では以下を改善しました。

- NICO SHELFの公開サイト上でTampermonkeyスクリプトが動作しているか、接続開始時に確認
- ニコニコタブとNICO SHELFの接続ハンドシェイクの再送
- タブ間の通知が届かない場合でもTampermonkeyの共有データを確認するフォールバック
- 連携処理の途中で「未接続」と見えて紛らわしい画面を「接続待ち」に変更
- 失敗時に「どちら側で通信が止まっているか」を分けて表示

マイリストデータ、SupabaseのSQL、OAuth、Cloudflareの環境変数の変更は不要です。ニコニコへの書き込みAPIは今回変更していません。

## v0.6からの更新方法

1. **NICO SHELFのデータを念のためJSONバックアップ**してください。
2. `src/main.js`、`src/bridge.js`、`bridge/nico-shelf-direct.user.js` をGitHubリポジトリの同じパスへ上書きしてください（`package.json` はバージョン表記のみの更新なので任意）。
3. Cloudflareの自動デプロイが成功することを確認してください。
4. ChromeでTampermonkeyのダッシュボードを開き、**古いv0.6の直接登録スクリプトを無効化**し、`bridge/nico-shelf-direct.user.js` をv0.6.1に更新してください。**同じ橋渡しスクリプトを2つ同時に有効にしないこと。**
5. Tampermonkeyのスクリプト詳細で `nico-shelf.shiokara-lab.workers.dev` と `www.nicovideo.jp` の両方に一致すること、およびChrome拡張機能のサイトアクセス権限があることを確認してください。Chromeで「ユーザースクリプトを許可」が必要な場合は有効にしてください。
6. **NICO SHELFのタブを完全に再読み込み（Ctrl+Shift+R）**してください。古い接続用ニコニコタブは閉じてかまいません。
7. 「＋ 動画を登録」→「① ニコニコと接続」→新しいニコニコタブで「接続を許可」を押してください。
8. NICO SHELFに戻り、**「ニコニコ連携：接続中」**になれば接続成功です。その後「② 登録状況を確認」を試してください。

### まだ接続できない場合

- **「NICO SHELF側で連携スクリプトv0.6.1が検出できません」**：NICO SHELFのタブでTampermonkeyのアイコンを押し、スクリプトが動いているか確認。アクセス権限やスクリプトの有効化を見直し、ページを再読み込み。
- **「NICO SHELF側のスクリプトは動作していますが、ニコニコ側から接続応答が届いていません」**：ニコニコタブのパネルで「接続を許可」したか、両サイトで同じ新しいv0.6.1を使っているか確認。
- **「NICO SHELF側スクリプトとの通信に失敗しています」**：Chromeの拡張機能によるサイトアクセス権限、Tampermonkeyの設定を確認。

## 検証状況

- JavaScript構文チェックに成功
- 従来の19件のローカル自動テストに成功
- Tampermonkey APIを模擬したタブ間通信テストで、通常通知・通知が届かないケースの双方に成功
- **Chrome/Tampermonkeyによる実サービスへの接続、ニコニコ本体での動画登録は未検証**。最初は「登録状況を確認」で読み取りだけ試し、書き込みは未登録の1件で確認してください。

## セキュリティ

- Googleの認証トークン、ニコニコのログインCookie、Supabaseの秘密鍵はアプリ間で転送しません。
- Tampermonkeyの共有保存領域には登録指示・処理結果が一時的に保存されます。
- 非公式APIなので本番登録は動作保証されず、仕様変更の可能性があります。
